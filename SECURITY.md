# Security Policy

## Supported Versions

The current repository package version is `2.0.0`. Security support follows the
maintained 2.x line.

| Version | Supported   |
| ------- | ----------- |
| 2.x     | supported   |
| <2.0    | unsupported |

## Reporting a Vulnerability

Report security issues via GitHub Security Advisories for gchigoo/repo-nav. Do not file public issues for vulnerabilities or secrets.
